Physical-factor evaluation data card

Exact construction, generation settings, exclusions, and machine-readable audits for the speed, pitch, and volume experiments used in the paper.

Scope. This is an evaluation release, not a training-data release. It redistributes controlled reference waveforms and generated outputs only; original VGGSound video and raw anchor audio are not included.

1. Recordings and interventions

Source recordings come from the held-out VGGSound test split and are disjoint from training. Speed and pitch each contain four classes × 32 recordings; volume contains eight classes × 16 recordings. Every factor therefore begins with 128 source recordings and is generated with seeds 3 and 4.

Each A/B pair is derived from the same source recording. Speed and pitch pairs are RMS-matched after editing. Volume is not RMS-matched because gain is the planned intervention. References exposed to the models are 5-s mono 44.1-kHz clips; each interface consumes the duration stated below.

3. Generation settings

All systems use the same two initial-noise seeds (3 and 4), 25 sampling steps, and 8-s mono 44.1-kHz output. Within a 2×2 group, the initial noise is identical across all four text/reference cells.

SystemGuidanceReference consumedStatus
RefCon-T2Atext α=3; reference β=15 sProposed AC-T2A interface
ControlFoleynative guidance 4.55 s semantic; first 2 s timbreZero-video diagnostic
AC-Foleynative guidance 4.52.02 sZero-video diagnostic; peak normalization disabled only for volume

ControlFoley and AC-Foley were trained with random dropout of conditioning modalities, so their released text and reference pathways can run without video; their authors did not evaluate this zero-video setting. The results characterize these end-to-end interfaces at the disclosed operating points.

4. Exclusion rule and retained counts

An item is excluded for all systems if any generated cell from any system has peak amplitude below 0.01 (−40 dBFS) or an undefined estimator. This common-set rule keeps comparisons paired and yields speed n=107, pitch n=119, and volume n=108.
