Matched Acoustic-Realization Listener

A complete qualitative companion to the matched counterfactual study: 22 groups, two fixed generation seeds, two compared systems, two text endpoints, and both reference endpoints. Select a group and seed, then compare the text-only and text-plus-reference outputs.

How to listen. “Aligned” uses matching text and reference endpoints; “conflict” crosses them. The reference signals and outputs are the exact WAV files used by the study. This page is for transparent qualitative inspection, not a listening-study claim.
Provenance. Each group fixes one held-out anchor and constructs two text-guided acoustic-realization endpoints. Reference and output audio are included; original source videos are not redistributed. The AC-T2A systems receive text and reference audio only. This static page contains no author, institution, account, or repository information.
