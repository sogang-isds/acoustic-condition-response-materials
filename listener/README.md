# Matched Acoustic-Realization Listener

Open `index.html` in a modern desktop browser. It works as a static local page;
if a browser restricts local media, run `python3 -m http.server` from this
directory and open the displayed local address.

Contents: all 22 matched groups, reference endpoints A/B, text-only A/B, and
the four text/reference cells for RefCon-T2A, ControlFoley, and AC-Foley, for
fixed seeds 3 and 4. This is a qualitative companion only. The paper's conclusions are
based on the reported group-level quantitative analysis, not informal listening.

The reference endpoints were produced by text-guided MMAudio using a fixed
anchor and seed during construction. The listener redistributes no source video.
