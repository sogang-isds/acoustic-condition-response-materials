# Physical Condition Controls

Static listener for deterministic examples from the paper's physical 2×2
experiments. It contains the first recording from each tested class that remains
in the common recording set: four speed, four pitch, and eight volume classes.
Both generation seeds, all three systems, text-only A/B controls, and all four
crossed text/reference cells are included. AC-Foley volume uses the paper's
two-seed, peak-normalization-off protocol. This is a qualitative aid, not a
listening study; the paper reports the common-set quantitative results
(speed n=107, pitch n=119, volume n=108).

Source clips are VGGSound-derived and released under its CC BY 4.0 dataset
terms. Cite Chen et al. (ICASSP 2020) when reusing these inputs. Original
VGGSound videos are not included.
