# Physical Condition Controls

Static listener for deterministic examples from the paper's physical 2×2
experiments. It contains the first source recording in each tested class:
four speed, four pitch, and eight volume classes. Both generation seeds and
both systems are included. This is a qualitative aid, not a listening study;
the paper reports the full n=128-per-axis quantitative result.

Source clips are VGGSound-derived and released under its CC BY 4.0 dataset
terms. Cite Chen et al. (ICASSP 2020) when reusing these inputs. Original
VGGSound videos are not included.
