Physical Condition Controls

Qualitative companion to the speed, pitch, and volume 2×2 tests. The subset is deterministic: the first source recording from every source class in the quantitative evaluation. For each item, hold text fixed and compare Reference A/B to hear reference response; hold reference fixed and compare Text A/B to hear text response.

Listening note. These are 8-second stochastic outputs, so an individual clip need not display the pooled mean visibly. Use both seeds and several classes. For volume, keep player and operating-system volume fixed and disable any loudness-normalization feature; the intervention is waveform signal level, not perceived source intensity.
