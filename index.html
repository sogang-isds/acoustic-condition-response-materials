Who controls the sound?

An acoustic reference can improve style and realization, but it can also silence a valid text instruction. These listening examples isolate which input changes the output.

Main observation. Under the same reference and generation seed, RefCon-T2A retains a larger audible response to text changes. The comparison is about residual text controllability, not a claim that one system always has better perceptual quality.
