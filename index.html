Who Controls the Sound? Measuring Text and Reference Control in Acoustic-Conditioned Text-to-Audio

An acoustic reference can improve style and realization, but it can also silence a valid text instruction. These listening examples isolate which input changes the output.

Main observation. Under the same reference and initial noise, all three systems follow the reference, but RefCon-T2A has the largest measured text response on every factor and keeps most of its no-reference text response, whereas the zero-video diagnostics lose most of theirs once a reference is attached. This is about residual text controllability, not audio quality.

Interpretation limits. ControlFoley and AC-Foley are zero-video diagnostics: their released text and reference pathways run without video, both were trained with random dropout of conditioning modalities, but their authors did not evaluate this setting. AC-Foley's peak normalization is disabled only for the volume test, and each system consumes the reference differently (RefCon-T2A 5 s; ControlFoley 5 s semantic / 2 s timbre; AC-Foley 2.02 s). Outputs with peak below −40 dBFS were excluded for all systems (speed 21, pitch 9, volume 20 recordings). A stronger response does not imply better audio quality.
